# Локальные шрифты

Подключение: `<link rel="stylesheet" href="/assets/fonts/fonts.css">`.

- `Montserrat` — основной шрифт, обычное начертание, веса 100–900.
- `Manrope` — текстовые блоки главной согласно макету, обычное начертание, веса 200–800.

Оба исходных variable TTF включают кириллицу и расширенную кириллицу, что также указано в сохранённых `METADATA.pb`. Файлы не модифицированы; курсив в этом наборе не включён.

Источники: официальный репозиторий [Google Fonts: Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat) и [Google Fonts: Manrope](https://github.com/google/fonts/tree/main/ofl/manrope). Рядом сохранены исходные лицензии SIL Open Font License 1.1. `sources.json` содержит ссылки на скачанные файлы и SHA-256.

Шрифты загружаются с сервера самого приложения; внешние запросы Google Fonts при отображении страницы не требуются.
