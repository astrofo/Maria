# Импорт анкет

Раздел «База волонтёров → Импорт анкет» доступен руководителю и администратору. Импорт создаёт новые профили волонтёров и черновики анкет. Совпадение почты, без учёта регистра, означает пропуск строки: существующие данные сохраняются.

## Порядок переноса

1. Скачайте шаблон в разделе импорта или подготовьте CSV-выгрузку портала. В Excel выберите сохранение CSV в UTF-8. Файлы XLSX напрямую не принимаются.
2. Заполните обязательные столбцы `full_name` и `email` (также принимаются «ФИО» и «E-mail»). Телефон, город и ответы анкеты можно добавить сразу.
3. Загрузите файл или вставьте CSV. Ограничения одной операции: 512 КиБ, 200 строк данных, 100 столбцов. Поддерживаются запятая и точка с запятой, кавычки и переносы строк внутри ячеек.
4. Нажмите «Проверить импорт». Предпросмотр покажет новые, повторные и ошибочные строки. Неизвестные столбцы будут перечислены в предупреждении.
5. Исправьте все ошибки и повторите проверку. Затем подтвердите создание новых профилей. Предпросмотр действует 10 минут в том же сеансе; после перезапуска сервера его нужно получить заново.

Минимальный пример:

```csv
full_name,email,phone,city
Анна Пример,anna@example.test,,Москва
Борис Пример,boris@example.test,,Самара
```

Примеры используют зарезервированный домен `.test`. В рабочем файле нужны настоящие адреса волонтёров.

## Поля

| Группа           | Столбцы                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Профиль          | `full_name`, `email`, `phone`, `city`, `birth_date` (YYYY-MM-DD), `gender` (`female`, `male`, `unspecified`)              |
| Сводные сведения | `skills`, `interests`, `experience`, `participation_format`, `participation_frequency`                                    |
| Полная анкета    | `questionnaire_json` или «Ответы анкеты целиком (JSON)» из выгрузки портала                                               |
| Отдельные ответы | Столбцы анкеты и уровней навыков из CSV-выгрузки портала; названия и допустимые варианты соответствуют действующей анкете |

Для списков внутри ячейки используйте `;` или `|`. При импорте `questionnaire_json` сервер проверяет тот же формат, что и форма анкеты; полная анкета имеет приоритет над отдельными столбцами ответов. Сводные интересы, навыки и доступность выводятся из анкеты.

## Доступ и история

Импорт не переносит роли, статус сотрудника, часы участия, согласия, дату завершения анкеты или подтверждение почты. Новая запись получает роль `volunteer`, статус `new` и не имеет доступного пароля. Пользователь входит по настоящему коду из письма, проверяет сведения и самостоятельно принимает документы фонда. Письма при импорте не отправляются. Адреса тестового списка `EMAIL_DEMO_ACCOUNTS` импортировать нельзя.

Перед применением права проверяются повторно. Одно подтверждение можно применить только один раз; данные берутся из проверенного предпросмотра. Если тот же email появился в базе после проверки, строка будет пропущена. Операция выполняется транзакционно, создание каждого профиля записывается в аудит без текста анкеты.

## API

- `POST /api/questionnaire-import/preview` — `{ csv }`; ответ: `{ summary: { total, create, skipped, invalid }, rows, warnings, can_apply, preview_token, expires_in }`.
- `POST /api/questionnaire-import/apply` — `{ preview_token, confirm: true }`; ответ: `{ created, skipped, total }`.

Требуются cookie-сессия и CSRF. В клиенте доступны `api.questionnaireImport.preview(csv)` и `api.questionnaireImport.apply(token)`. После неясного результата применения сначала проверьте базу волонтёров; повторный импорт пропустит уже созданные адреса.
